# Foundry VTT — макросы для DnD Economy

Два скрипт-макроса, использующие `api/items/search` и `api/items` (см. `src/DndEconomy.Web/Controllers`)
для доступа к экономике сайта прямо из Foundry.

- `uznat-cenu.js` — любой игрок вводит название предмета и получает окно с точным названием и ценой.
- `sozdat-predmet.js` — только ГМ: выбирает предмет из Items directory мира, подтверждает поля
  и создаёт запись в каталоге сайта (роль Admin).

## Установка

1. В Foundry: вкладка Macros → Create Macro → тип **Script**.
2. Скопируйте содержимое нужного файла целиком в редактор макроса.
3. В начале файла впишите email/пароль в константу `LOGIN` (`uznat-cenu.js`) или `ADMIN_LOGIN`
   (`sozdat-predmet.js`) — **только в самом макросе внутри Foundry**, не в этом файле в git:
   правьте копию в редакторе макроса, а не версию в репозитории, иначе пароль попадёт в историю
   коммитов.
4. Сохраните макрос, перетащите на хотбар.

## Требования на стороне сайта

- CORS разрешён только для origin, заданного в `CorsPolicyNames.FoundryVtt` (см. `Program.cs`) —
  сейчас это `https://relaxerr-dnd.ru`. Если Foundry живёт на другом домене/порте, поправьте
  `WithOrigins(...)` там же.
- Макросы логинятся через `POST /api/auth/login` (JSON, для кросс-доменных клиентов — обычная
  SSR-форма `/Account/Login` для скрипта не подходит) и используют ту же cookie-сессию Identity
  для последующих запросов.
