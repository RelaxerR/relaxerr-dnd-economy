### Исправления

- Готовность push зависит от всех трёх параметров VAPID, валидного контакта и совпадения
  публичного/приватного P-256 ключа. Ошибка показывает только имена отсутствующих параметров
  либо безопасную причину; некорректная конфигурация не запускает отправку.
- Кнопка подключения привязывается после асинхронной загрузки настроек, а не единственный раз
  при первом render без кнопки. Смена VAPID-пары на сервере объясняет необходимость переподписки.
- Генератор ключей пишет только новый файл `0600`, без приватного ключа в stdout/stderr.
  Существующая пара никогда не перезаписывается. `.env`-файлы исключены из git и Docker context.
- Новый файловый volume доступен непривилегированному `app` в Docker. Для прежних root-owned
  volumes добавлена точная одноразовая инструкция проверки/исправления.
- При браузерном выборе слишком большого файла размер проверяется до создания сообщения.
  До исправления проверка нашла лишнее текстовое сообщение и английскую ошибку OpenReadStream;
  теперь выбор отклоняется русским сообщением. Повторная UI-проверка именно исправления не завершена.

### Оставшиеся проверки и production

SSH `deploy@77.110.104.211:22` дважды завершился `Connection timed out during banner exchange`,
хотя TCP-порт доступен. Это до проверки ключа, а не доказательство неверного ключа или firewall.
Предыдущий Deploy в Actions был успешным. В текущем проходе серверный firewall/.env не читались
и не менялись, новый deploy не запускался. После уточнения пользователя настройка на сервере
передана ему отдельным сообщением для ChatGPT. **Production VAPID-пара здесь не создавалась**:
наличие прежней пары и секретного backup на сервере не установлено. Генерировались только
одноразовые тестовые ключи вне репозитория. Без фактической настройки production предупреждение
на рабочем сайте ожидаемо остаётся; этот PR сам по себе не включает push на сервере.

Открыты два настоящих браузера (Chrome p1, Safari p2) на локальном стенде; история и вложение
видны обоим. Полный управляемый обрыв с правками второго клиента не завершён: CUA начал
возвращать `The user changed ...` в обоих приложениях. Нет основания считать reconnect пройденным.
Стенд предоставляет отдельные proxy 5291/5292 для повторения без отключения сети компьютера.

Не выполнены: повторная UI-проверка исправленного oversize, полный reconnect и отзыв прав
в двух живых клиентах, фактическая установка/подписка/доставка Web Push, Android Chrome,
iPhone с домашнего экрана, полный сквозной пользовательский сценарий на телефоне,
100 МБ через **рабочий** nginx/CDN. Локальный HTTP nginx не заменяет TLS/CDN рабочего сервера.
