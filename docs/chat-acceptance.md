| Экономическая связь | Два параллельных сохранения дают одну сессию; чужой игрок отклонён; отменённую нельзя закрепить |

| Web Push с подменённой сетью | Настоящая генерация ключей, VAPID и шифрование, одна доставка при повторном проходе, удаление подписки после 410, отклонение неподдерживаемых URL |
| Chrome, отдельная тестовая БД | Cookie-вход, отправка и отображение сообщения, прочтение, переход в календарь, сохранение окна и обновление покрытия |
| Chrome Responsive 400 px | Проверены список/лента; обнаруженное переполнение общей навигации исправлено и повторно проверено; перезагрузка восстановила сообщение |

Команды воспроизведения находятся в [эксплуатационной инструкции](chat-operations.md). TRX формируется через `--logger 'trx;LogFileName=tests.trx'`; CI сохраняет его artifact. Полный сетевой обрыв с изменениями другим браузером не имитировался: автоматическая проверка подтверждает восстановление серверного снимка, браузерная — восстановление при reload с новым WebSocket.
