# Промпт для Codex

Реализуй чат и планирование партий в `RelaxerR/relaxerr-dnd-economy` на ветке `codex/chat-and-session-scheduling`. Начни с актуальной опубликованной версии этой ветки. Прочитай `AGENTS.md`, `docs/chat-and-session-scheduling.md` и GitHub issues #18–#27. Спецификация и задачи задают объём работы и критерии приёмки. Используй предложенные в спецификации умолчания, а существенные уточнения задокументируй в ней.

1. Реализуй задачи с учётом зависимостей:
   - #18 — главный и дополнительные чаты, история, realtime, статусы и управление сообщениями.
   - #19 — личные сообщения, ветки, архив и поиск.
   - #20 — вложения и очистка.
   - #21 — обычные опросы.
   - #22 — календарь, повторы и конвертация времени.
   - #23 — подбор, состав и сортировка окон.
   - #24 — запрос календаря, голосование, назначение, отмена и новый подбор.
   - #25 — интеграция с экономическими сессиями.
   - #26 — уведомления и Web Push.
   - #27 — сквозная приёмка и эксплуатационная документация.
2. Встрой работу в существующий .NET 10 / Blazor Server / PostgreSQL проект. Используй действующие Identity, роли, страницы и сервисы, где они подходят. Сохрани существующую авторизацию, Foundry и поведение экономики. Добавь безопасные для существующих данных миграции. Проверяй права на сервере для истории, поиска, realtime, вложений, веток и пушей, в том числе при прямых ссылках и переподключении.
3. Доведи работу до интегрированного результата на этой ветке. Проверь сборку, тесты, миграции и сквозные сценарии из спецификации. Зафиксируй результаты отдельно от проверок, которые требуют реального устройства или окружения. Если проверка недоступна, опиши точную причину и шаги воспроизведения.
4. Запушь ветку и открой PR в `main` с результатами проверок. Добавь в описание по одной строке `Closes #18` … `Closes #27` для всех задач, критерии которых выполнены. GitHub закроет связанные issues при слиянии PR. Оставь задачи с невыполненными критериями открытыми и укажи конкретные пробелы. Слияние и запуск продакшен-деплоя требуют отдельного поручения.
