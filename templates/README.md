# Шаблоны для импорта экономики

Четыре шаблона под `/admin/import` — по одному на каждый лист, который понимает
`ExcelEconomyImportService`:

| Файл | Лист | Что содержит |
|---|---|---|
| `economy-items.xlsx` | Предметы | Справочник товаров каталога |
| `economy-cities.xlsx` | Города | Города и коэффициенты стоимости "Тип+Подтип × Город" |
| `economy-seasons.xlsx` | Сезонность | Коэффициенты стоимости "Тип+Подтип × Сезон" |
| `economy-settings.xlsx` | Настройки | Игровые сессии ("Партии"): город/сезон/коэффициенты на дату |

В каждом файле два листа: "Инструкция" (описание колонок и формата) и рабочий лист с
точным названием из таблицы выше — именно по названию листа `ExcelEconomyImportService`
решает, какие данные импортировать.

Файлы можно загружать по одному (в любом порядке и в любой момент — например, сначала
`economy-cities.xlsx`, а через неделю `economy-items.xlsx`) или объединить нужные листы
в одну книгу и загрузить её целиком — импортёр обрабатывает каждый лист независимо, если
он присутствует в файле. Повторная загрузка безопасна: существующие записи обновляются по
ключу (UUID предмета, имя города/сессии, пара Тип+Подтип), а не дублируются.
