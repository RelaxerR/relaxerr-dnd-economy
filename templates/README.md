# Шаблоны для импорта экономики

Пять шаблонов — по одному на каждый лист, который понимает `ExcelEconomyImportService`.
Импорт и экспорт больше не собраны на одной общей вкладке — у каждого листа своя страница
в разделе «Города и сессии» админки (или «Предметы» для листа «Предметы»), там же кнопка
«Скачать текущее (.xlsx)», отдающая файл в актуальном состоянии БД в том же формате.

| Файл | Лист | Что содержит | Страница в админке |
|---|---|---|---|
| `economy-items.xlsx` | Предметы | Справочник товаров каталога | `/admin/items` |
| `economy-cities.xlsx` | Города | Города и коэффициенты стоимости "Тип+Подтип × Город" | `/admin/economy/cities` и `/admin/economy/city-modifiers` (один и тот же лист) |
| `economy-seasons.xlsx` | Сезонность | Коэффициенты стоимости "Тип+Подтип × Сезон" | `/admin/economy/season-modifiers` |
| `economy-settings.xlsx` | Настройки | Игровые сессии ("Партии"): город/сезон/коэффициенты на дату | `/admin/economy/sessions` |
| `economy-coin-acceptance.xlsx` | Приём монет | Доля приёма номиналов по городам + заметки | `/admin/economy/coin-acceptance` |

Матрицы коэффициентов (`economy-cities.xlsx`, `economy-seasons.xlsx`) не нужно вручную
пополнять строками при добавлении новой категории предметов — на соответствующих
страницах админки (и, соответственно, в экспортированном файле) строки подставляются
автоматически по всем реальным парам Тип+Подтип из каталога.

В каждом файле два листа: "Инструкция" (описание колонок и формата) и рабочий лист с
точным названием из таблицы выше — именно по названию листа `ExcelEconomyImportService`
решает, какие данные импортировать; остальные листы книги (если они есть) игнорируются.

Файлы можно загружать по одному на профильной странице или объединить нужные листы в одну
книгу — импортёр всё равно прочитает из неё только тот лист, что нужен текущей странице.
Повторная загрузка безопасна: существующие записи обновляются по ключу (UUID предмета,
имя города/сессии, пара Тип+Подтип, пара Город+Номинал), а не дублируются.
